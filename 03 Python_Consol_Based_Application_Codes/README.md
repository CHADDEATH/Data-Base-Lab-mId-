# Pak Voyage – Python Application Guide

## Quick Start
1. Ensure Oracle Database 26ai is running.
2. Execute the 10 SQL scripts in `../02_SQL_Code/` in numerical order (via Oracle SQL Developer).
3. Verify your Oracle connection details in `config.py` (copy from `config_example.py` if needed).
4. Run `python data_import.py` to import all 17 Excel datasets (over 1,200 records).
5. Run `python main.py` or double-click `run.bat` to start the console application.
